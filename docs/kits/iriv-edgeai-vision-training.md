# IRIV EdgeAI Industry 4.0 Vision Training

<img src="https://static.cytron.io/image/cache/catalog/products/V-KIT-IRIV-EAI/edge-ai-kit-a-800x800.png" alt="IRIV EdgeAI Industry 4.0 Training Kit" width="360" loading="lazy" />

**Product code:** V-KIT-IRIV-EAI (kit + training option: KIT-IRIV-EAI-SP) · [Product page](https://my.cytron.io/cytron-industry/iriv-edge-ai-training-page)

A two-day Edge AI vision workshop by Cytron, sold with an IRIV EdgeAI industrial training kit that participants take home. You learn Node-RED, Modbus RS485 and Blynk, then Hailo AI detection, preparing your own dataset, training a custom model and linking AI results to physical outputs.

## Training Kit Contents

Industrial training box with DIN rails and cable management, holding:

| Qty | Item |
|---|---|
| 1 | [IRIV EdgeAI CM5](../products/iriv-edgeai-cm5/index.md), **8GB RAM / 32GB eMMC, 13 TOPS** Hailo AI accelerator |
| 1 | Meanwell 24V 100W DC power supply |
| 1 | AC socket |
| 1 | Industrial relay, 24 VDC coil (24 VDC / 240 VAC contacts) |
| 1 | Industrial illuminated push button, 24V |
| 1 | RS485 industrial temperature and humidity sensor |
| 1 | Acrel ADL200 RS485 power meter (240 VAC) |
| 1 | USB camera, 8 MP (IMX219), autofocus, UVC |

Software (with the training session): Raspberry Pi OS Bookworm, a pre-built Node-RED dashboard, and Node-RED and Python libraries for the AI vision application.

:::note 13 TOPS, not 26
This kit uses the 13 TOPS configuration. The 26 TOPS version is used in the [Safety Box Kit](./iriv-edgeai-safety-box-kit.md).
:::

## Workshop

| Item | Detail |
|---|---|
| Duration | 2 days |
| Included | Training kit to keep, meals, professional certificate |
| HRDC | Claimable — see [How to claim HRDC](https://my.cytron.io/tutorial/how-to-claim-hrdc-training) |
| Scheduling | No fixed public dates — request a session through the product page |
| Bring | A **Windows** laptop. For custom model training, Intel Core i5 10th Gen / AMD Ryzen 5 5th Gen or better with 16GB RAM is recommended; a pre-trained model is provided if training does not finish in time |
| For | Engineers, system integrators, lecturers and trainers |

**Outline:** getting started with Node-RED · Node-RED input and output · Modbus RS485 · Blynk IoT · Linux command line · basic Python · Hailo AI basic detection pipeline · custom dataset preparation · Hailo inference on images and video · Hailo inference driving buzzer and LED outputs · inference with a custom-trained model · integrating AI results with Blynk.

## Cameras

The controller has 2 × USB 3.0 and 2 × MIPI CSI ports, so up to four cameras can be connected. The two USB ports share one hub, so four full-rate streams are not guaranteed.
