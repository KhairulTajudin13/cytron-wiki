# Products

Welcome to the Cytron products documentation hub. Browse our industrial-grade controllers and automation solutions designed for Industry 4.0 applications.

## Available Products

- [**IRIV PiControl**](./iriv-picontrol/) - Industrial controller powered by Raspberry Pi Compute Module 4, featuring isolated I/O, serial communication, and expansion options in a DIN rail-mountable enclosure.

- [**IRIV IO Controller**](./iriv-io-controller/) - Industrial I/O controller powered by Raspberry Pi RP2350 microcontroller, designed for lightweight automation with digital and analog I/O, RS485, and Ethernet in a compact DIN rail-mountable enclosure.

- [**IRIV SmartHub CM5**](./iriv-smarthub-cm5/) - Industrial gateway and controller powered by Raspberry Pi Compute Module 5, designed for edge computing, system integration, and industrial automation applications.

- [**IRIV EdgeAI CM5**](./iriv-edgeai-cm5/) - Industrial edge AI controller powered by Raspberry Pi Compute Module 5, designed for AI inference, vision-based applications, and high-performance edge processing.
