## Getting Started

### Getting Started with IRIV IO Controller with CircuitPython

**Level:** Beginner
**Author:** Hussien Jawhar Sathik
**Published:** November 11, 2024
**Link:** [Getting Started with IRIV IO Controller with CircuitPython](https://my.cytron.io/tutorial/getting-started-with-iriv-io-controller-with-circuit-python)

Comprehensive beginner tutorial designed to help users start working with the IRIV IO Controller immediately. This guide covers essential topics for out-of-the-box functionality.

**Topics Covered:**
- Power management and programming setup
- CircuitPython firmware installation
- Interface control (buttons, LEDs, buzzers)
- Digital input and output operations
- Analog input measurement
- Real-time clock (RTC) functionality
- RS485 and MODBUS RTU communication
- Ethernet connectivity and internet integration
- IoT gateway implementations (Blynk, ThingSpeak, MQTT)
- Practical application: agricultural automation

This tutorial includes links to 14 related subtutorials covering specific features and applications.
