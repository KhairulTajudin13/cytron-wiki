# Page templates

Copy a template into the right `docs/` folder, rename it, fill in the `<...>` parts and delete the hints in `<!-- -->` comments. Then add the page to `sidebars.js`.

| Template | Use it for |
|---|---|
| [`product-page.md`](product-page.md) | A new page in a product section (overview, hardware, software setup, etc.) |
| [`tutorial.md`](tutorial.md) | A step-by-step guide that ends with something working |
| [`troubleshooting-entry.md`](troubleshooting-entry.md) | One problem and its fix, to paste into a product's Troubleshooting page |

This folder is not published on the site.
